# Activitat-Login
Activitat 1: Login de Accés a Dades 2DAMVI 25-26


Generar un projecte nou de Unity i afegir SQLite

Generar una taula de usuaris a una base de dades SQLite continguda amb els següents atributs:
UserID Primary Key AutoIncrements 
Username Unique
Password Must be at least 8 digits long

Generar una petita interfície d’usuari a Untiy que permeti registre i login amb usuari/contrasenya existents a la base de dades utilitzant Queries directament contra la base de dades des de Unity. S’ha de gestionar mostrar d’alguna manera les exepcions de usuari no trobat/contrasenya equivocada (popup d’error a l’aplicació) i s’ha de canviar d’escena quan es realitzi el login, a més de permetre la “desconnexió”.

L’entrega consisteix en un repositori de Github amb una build a l’apartat de releases.
